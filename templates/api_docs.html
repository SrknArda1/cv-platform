Veri API'si

Platformun anonim veri seti. Dış sistemler bu adreslere istek atarak JSON veya CSV alır; giriş gerekmez.

Kişisel veri dönmez. Ad, e-posta, telefon ve transkript bu API'de yoktur. Serileştirme katmanı veritabanı modelini değil, açıkça seçilen alanları döndürür — modele yeni bir kolon eklendiğinde yanlışlıkla dışarı sızmaması için.

Ayrıntılı metrikler: kayıt eğrisi, onay hunisi, mesaj hacmi. API anahtarı gerektirir — X-API-Key başlığı olmadan 401 döner.

Filtreler

/api/v1/ogrenciler adresi aşağıdaki sorgu parametrelerini kabul eder. Birden fazlası birleştirilebilir ve hepsi CSV çıktısıyla da çalışır.

ParametreDeğerNe yapar
page1, 2, 3…Sayfa numarası
page_size1–200Sayfa başına kayıt (varsayılan 50)
departmentbölüm adıTek bölüme indirger
skillmetinYetkinlik araması, büyük/küçük harf duyarsız
has_transcript1 / 0Transkripti olan / olmayan
verified1 / 0Transkripti doğrulanmış olanlar
min_completion0–100Profil doluluğu eşiği
formatcsvJSON yerine CSV indirir
delimitercommaCSV ayırıcısını virgüle çevirir

Örnek — profili en az %25 dolu adayları Excel için indirir: 

/api/v1/ogrenciler?min_completion=25&format=csv

Her yanıt aynı iskelette döner — hata da dahil. Böylece istemci tek bir ayrıştırıcı yazar: data veriyi, meta veri hakkındaki bilgiyi (toplam, sayfa), links gezinme adreslerini taşır.

Kullanım

Excel: Veri → Veri Al → Web'den. Aşağıdaki adresi yapıştırın; dosya indirilmez, tablo canlı bağlanır ve “Yenile” dendiğinde sunucudan tazelenir. 

{{ taban }}/api/v1/ogrenciler?format=csv

Python (pandas):

import pandas as pd, requests

veri = requests.get("{{ taban }}/api/v1/ogrenciler?page_size=200").json()
df = pd.DataFrame(veri["data"])

Korumalı uç nokta:

curl -H "X-API-Key: ANAHTAR" {{ taban }}/api/v1/ozet/detay

Sınırlar

  • Dakikada 120, saatte 2000 istek. Aşımda 429 döner.
  • Yalnızca GET. API salt-okunurdur; yazma uç noktası yoktur.
  • Yanıtlar 60 saniye önbelleklenebilir (Cache-Control).
  • CORS açıktır: tarayıcıdaki JavaScript başka alan adından okuyabilir.
